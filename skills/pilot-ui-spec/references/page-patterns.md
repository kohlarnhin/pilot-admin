# 页面组合

## 标准管理列表

一张白色、16px 圆角卡片占满剩余高度。标题/搜索/actions、表头固定，真实 body 滚动。默认每页 20 条无限追加，行虚拟化。姓名/代码柔性列，状态紧凑，时间等宽不换行，操作列固定宽。标准表格在 1280×720 展开侧栏时可见操作列且无横向滚动。

初次加载匹配表头和约 7 行骨架；刷新保留现有行；正常追加安静；空态居中在同一 body；错误有明确重试。查询更新要重置分页、保留代次隔离，不能把失败当成无数据。

用户管理使用 350ms 防抖的搜索即输入；创建/编辑使用字段内校验、异步保存和一次性密码结果。角色管理使用平面权限树、non-routed 权限组与按钮粒度授权。菜单管理保持树与按钮名称覆盖，不改变静态稳定 id。

## 设置

系统设置采用两面板：分类 256px（≥1280px 时 288px）与柔性内容，间隔 16–20px。分类项 12px 角，横 padding 16px、纵 10–14px，36px 图标块、14px 标题、11px 描述，active 为 slate-100 细框。两侧有自己的有限高度与滚动，必要保存 footer 固定。

助手设置沿用紧凑 Section 卡片：模型列表、助手名称/问候语与实时预览、最多 6 条快捷提问。模型表单 460px，最多 150 字符的模型字段；API key 掩码展示。没有查看权限不能渲染配置数据，没有修改权限只读。

## 概览

概览允许在 main 内单一滚动；侧栏固定。指标网格桌面 4 列、间隔约 20px，值 24–30px/等宽，标签 12–13px。卡片 12–16px 角、20–24px padding，主区间隔约 24px。使用实际数据的指标、待办和活动，不为装饰而添加图表。

## 登录

独立自然滚动白色页面，380px 最大表单宽，横 padding 16px、纵 40–48px；22px/600 品牌标题，12–13px 描述，40px 高输入和 slate-900 主按钮。错误内联、不改变宽度，编辑字段立即清错，焦点移到错误字段。保留演示账号快捷填入、禁止重复提交和 Agent 入口选择。

## Agent 与助手

管理页上的非模态面板和 `/agent` 共用路由上层唯一 Runtime，消息、草稿和生成过程不因宿主切换重启。Agent 页 56px 顶栏、260px 历史列，消息内容最大宽约 760px、composer 外层约 792px。

从 Agent 打开页面带安全的 agentReturnTo 状态，在管理外壳出现返回条；只能返回本站 `/agent` 及其会话参数。角色失去 agent:use 后，面板消失、Agent 路由 403。没有配置时显示单一明确空态，并仅给有权限的账号设置入口。

## 选择方式

记录对比与 CRUD 用列表；分类配置用设置；跨资源汇总用概览；临时结构化任务用弹窗；持续自然语言任务用助手/Agent。保持共享 tokens 与滚动契约，不把所有页面都做成卡片网格或巨型表格。
