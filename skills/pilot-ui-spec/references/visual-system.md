# 视觉系统

## 表面与色彩

紧凑的桌面管理界面，白色主区域、极浅冷灰次级表面、1px 边界与克制阴影。层级通过对齐、留白和字体表达，不添加营销 hero、大块饱和色或装饰渐变。

| 色阶 | 数值 | 用途 |
| --- | --- | --- |
| brand | #FDA92D | 品牌、当前位置、tab 下划线、进行中、新内容标记 |
| brand-600 | #F59E0B | 较强进行中信号、助手流式点 |
| brand-700 | #A85D13 | 白底可读品牌文字，约 4.95:1 对比 |
| brand-800 | #793908 | 少量强品牌文字 |
| brand-200 | #FED680 | 辅助品牌点 |
| brand-100 / 50 | #FEF4D4 / #FFF8EB | 少量语义品牌表面，不能作为通用 hover |
| 完成进度 | #10B981 / 80% | 覆盖率、完成条 |

普通按钮白底、#E2E8F0 边框、slate-800 字；hover 用 slate-50 / slate-300 / slate-900。唯一最强操作可用 slate-900 实心、白字，hover slate-800。focus 为 2px slate-400，输入 halo 为 3px rgba(15,23,42,.1)。checkbox/switch 的选中态为 slate-900，选中背景 slate-100；危险操作红色，hover #DC2626 / #FEF2F2。橙色不能替代上述中性交互状态。

全局背景 token 可以是 #F4F6F8，认证外壳与登录页仍明确涂白。Tag 默认白底细框加 6px 语义点，避免每个单元格都使用浓重底色。

状态色延续现有 tokens：success #36B37E（深字 #1B806A）、warning #FFAB00（#B76E00）、error #FF5630（#B71D18）、info #00B8D9（#006C9C），soft 背景约 15%。状态同时提供文字/图标，不能只依赖颜色。

## 字体与文字

本地托管 Open Sans Variable、Noto Sans SC 的 400/500/600 与 JetBrains Mono。正文 400，强调 500，部分标题 600，避免中文满屏粗体。

| 元素 | 大小/字重 |
| --- | --- |
| 侧栏产品名 / 副文案 | 15–16px / 500–600；11px |
| PageHeader | 20px / 600，轻微负字距 |
| 卡片标题 | 16px / 500–600，20–24px 行高 |
| 表头 | 12px / 500，slate-500，20px 行高，字距 .01em |
| 表格正文 | 13px / 400，20px 行高 |
| 输入 | 13px / 400，36px 高内垂直居中 |
| 时间、标识、代码 | 11–12px，等宽，不自动挤压操作列 |
| 导航组 | 11px / 500 |
| 指标数值 | 24–30px / 500–600，等宽或 tabular-nums |
| 登录标题 | 22px / 600 |

有意义的文字不低于 11px。重要提示、空态说明与可交互文字用 slate-500 或更深；slate-400 只用于非关键元信息。文本保持可选择和复制。

截断链先 `min-w-0`，再 ellipsis/nowrap；截断标题、ID、代码必须有完整 `title`、详情或复制路径。CodeTag 自动提供 title。详情使用 pre-wrap 和 overflow-wrap:anywhere，时间常用 YYYY-MM-DD HH:mm，必要时 tooltip 显示秒。

## 间距、圆角与阴影

| 关系 | 数值 |
| --- | --- |
| 图标与文字 | 6–8px |
| 工具栏控件 | 10px，局部可用 8/12px |
| 标题图标与正文 | 12–14px |
| 主区域 padding | 16px；≥1024px 时 24px |
| 设置分栏 / 卡片网格 | 16–20px / 20–24px |
| 常规卡片标题 padding | 横 24px、纵 20px |
| 紧凑标题 padding | 横 20/24px、纵 16px |
| 正文区 / 内部卡片 | 24px / 12–16px |
| 表格 body | 外 padding 0；单元格横 16px |
| 固定编辑行 | 实际 56px，常见纵 padding 8px |

控件圆角 8px，内部卡片 12px，主卡片/弹窗/助手 16px，Tag 6px；角色权限弹窗保留 10px 局部变体。边界以当前组件的实线为准。阴影直接复用 `tailwind.config.js` 的 card、pop、overlay、xs、2xs，不增加多层光晕。

## 图标与动效

使用当前 Lucide 体系：导航 18–20px、mini 22px、图标槽 22px；操作 14–18px。不要混入第二套图标依赖。动画短且克制，常规状态 120–200ms，侧栏宽度约 300ms，助手入场 180ms，历史滑层 240ms；尊重 prefers-reduced-motion。阴影、图标和装饰不能阻止数据选择。
