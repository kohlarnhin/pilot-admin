# UI 验收

在运行中的真实应用操作；静态 assets 或模拟 fixture 只能补充，不能代替真实数据路径。报告已跑检查、环境、结果和限制，不声称未做的像素对比。

## 几何与视觉

- 1440×900：侧栏 224 /88px，品牌 64px；管理区没有全局顶栏，白色主表面，16/24px padding，Card 16px、内部12px、控件8px。
- 1280×720、侧栏展开：用户/角色等标准表格无横向滚动，操作列完整，document 不滚动。折叠后 logo 居中且状态刷新保留。
- 普通控件 36px；表头44–45px；正文12–14px，有意义文字≥11px。本地字体、状态/hover/focus/disabled 正确。
- 中性交互层，橙色只用于品牌、位置、进行中。长文本有 title 或完整查看/复制路径。
- 页面、表格、历史、弹窗 body 的 min-h-0/min-w-0 高度链正确；头尾固定，内容增长不移动相邻面板。

## 列表与表单

1. 让数据溢出，滚动实际表格；标题、工具栏、表头、侧栏保持位置。
2. 记录加载行数，接近底部触发追加；每批20，单请求，DOM 挂载少于已加载总数；无页码或常驻加载更多。
3. 切换查询时没有串页；刷新保留行，初次/追加失败有显式重试、无自动风暴。
4. 新增、编辑、启停、重置密码、确认删除可用；localStorage 刷新持久，重置恢复种子。
5. 空必填/错误字段有内联提示、aria-invalid 和关联描述；输入后清错。异步保存期间禁止重复提交和关闭，失败保留值。
6. 创建用户未输入密码时生成默认10位随机值，成功结果只出现一次并可复制；更严格策略使用其长度。
7. 三种角色菜单/路由/按钮遵循授权；角色修改经 me 刷新立即反映。

## 搜索与覆盖层

Cmd/Ctrl+K 打开、Esc 关闭、方向键选择、Enter 跳转并归还焦点；最近访问按用户持久化，无记录时有提示；查询只命中用户时不渲染空页面组。

Tooltip、Popover、Dropdown、Modal、Confirm、Drawer、toast、文件选择器和表单错误在真实 gallery 中操作。弹层有正确名称与 focus，内容很长仍能到达 footer，overlay 顺序正确。缩短视口后无不可达操作。

## 助手与 Agent

1. Ctrl/⌘J 打开440px 面板，右下24px、height min(760px,viewport−48px)；1280×720 同样适配。展开720px 不盖住侧栏，无悬浮启动球。
2. 思考/进度、delta、Markdown 表格和代码、停止/重试均可见且可操作。停止后新会话无迟到 delta。
3. choices → confirmation → service 写入，selection 至少1项，modal action 完成/取消都保存终态并续接摘要；页面无需 reload 更新数据。
4. 4步巡检运行/完成/报告；中途停止只让当前步完成，其余显示停止，恢复历史不自动重跑。
5. 运行中切换 panel ↔ `/agent` 保留同一会话、草稿和请求；Agent 历史 sidebar 无限追加，长会话向上加载更早消息并保留锚点。
6. 从 Agent 打开授权页面，返回条回到同一会话。未授权页面被拒绝；撤销 agent:use 后 panel 消失且 Agent 403。
7. ask/记住选择/下次登录和账号菜单偏好正确，viewer 没有入口。
8. profile/快捷提问和模型 CRUD、掩码密钥生效；无启用配置为空态且输入禁用。
9. 附件 chip 有解析/移除，ack 仅元数据，文件正文未进入消息/localStorage/请求。通知只因实时完成触发，不因历史恢复重复。
10. session/message 数量有上限，损坏/旧 DB 回退种子，重置连同助手会话/草稿恢复种子。
